# Think Better — 91 Day Thinking Gym

A mobile-first offline-friendly web app for:
- Mental-model flashcards
- 91-day practice plan
- Daily reps (focus, learning, courage, body, review)
- Reflection journal
- Decision journal
- Favorites
- Local progress persistence
- Light/dark mode

## Run locally
Open `index.html` in a browser.

For PWA install/offline support, serve the folder from a local/static web server, e.g.:
`python3 -m http.server 8080`

Then open http://localhost:8080

All user data is stored in browser localStorage.
